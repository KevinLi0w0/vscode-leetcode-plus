# 42 接雨水

## 标签
双指针

## 核心思路
双指针从两端向内移动，维护 `leftMax` 和 `rightMax` 分别记录左侧和右侧的最大高度。哪边的最大值更小，就处理哪边——因为较小的一侧决定了该位置能接的雨水量。时间 O(n)，空间 O(1)。

## 代码模板
```python
class Solution:
    def trap(self, height: List[int]) -> int:
        if not height:
            return 0

        left, right = 0, len(height) - 1
        leftMax, rightMax = 0, 0  # 分别记录左右两侧的当前最大高度
        water = 0

        while left < right:
            # 哪边的最大值更小，就处理哪边
            # 因为较小的一侧决定了该位置的水位
            if leftMax < rightMax:
                # 左侧较矮，处理左指针
                leftMax = max(leftMax, height[left])
                water += leftMax - height[left]  # 可接的雨水量
                left += 1
            else:
                # 右侧较矮或相等，处理右指针
                rightMax = max(rightMax, height[right])
                water += rightMax - height[right]
                right -= 1

        return water
```

## 关键点
- 每个位置能接的雨水 = min(左侧最大高度, 右侧最大高度) - 当前高度
- 处理较矮的一侧：因为该侧的最大值是瓶颈，决定了水位
- 维护 leftMax / rightMax 只需 O(1) 空间

## 易错点
- 先更新 leftMax/rightMax 再计算雨水量，否则会用旧值
- 当 leftMax < rightMax 时处理左边，不是处理较矮的那个 height[left]
- 空数组要提前返回 0
