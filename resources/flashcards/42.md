# 42 接雨水

## 📖 故事
一排高低不等的积木，下雨后凹槽会积水。每个位置能积多少水，取决于它左边最高的积木和右边最高的积木中较矮的那个，减去自己 Höhe。双指针从两端往中间走，各自记住左边/右边见过的最高积木，矮的那边先算。

## 🗣️ 人话对照表
| 代码里的 | 人话 |
|----------|------|
| `left`, `right` | 从两端往中间走的两个指针 |
| `leftMax` | 左边走过来见过的最高积木 |
| `rightMax` | 右边走过来见过的最高积木 |
| `min(leftMax, rightMax)` | 木桶效应：水高度取决于矮的那边 |
| `min(lm,rm) - height[i]` | 这个位置能积的水 = 水位 - 自己的高度 |

## 📝 带注释课文
```python
class Solution:
    def trap(self, height: List[int]) -> int:
        left, right = 0, len(height) - 1
        leftMax, rightMax = 0, 0
        water = 0

        while left < right:
            # 哪边矮就处理哪边
            # 因为矮的那边的水量已经被另一边的最大值兜住了
            if height[left] < height[right]:
                # 左边矮，看 leftMax 能不能兜住当前格
                if height[left] >= leftMax:
                    leftMax = height[left]  # 更新左边最高
                else:
                    water += leftMax - height[left]  # 可以积水
                left += 1
            else:
                # 右边矮，同理
                if height[right] >= rightMax:
                    rightMax = height[right]
                else:
                    water += rightMax - height[right]
                right -= 1

        return water
```

## ⚠️ 易错点
- 先更新 leftMax/rightMax 再判断积水：如果当前格比已记录的最高还高，说明这格积不了水，要更新最高值
- `height[left] < height[right]` 时处理左边，不是 `leftMax < rightMax` 时
- 双指针不需要回到中间汇合后再算，走到 `left >= right` 就停
