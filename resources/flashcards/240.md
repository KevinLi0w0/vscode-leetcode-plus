# 240 搜索二维矩阵II

## 📖 故事
在一个从左到右、从上到下都递增的表格里找数。从右上角开始最聪明：站在右上角，比目标大就往左走（变小），比目标小就往下走（变大）。像一个直角导航，每一步都能排除一整行或一整列。

## 🗣️ 人话对照表
| 代码里的 | 人话 |
|----------|------|
| `row = 0, col = n-1` | 从右上角出发 |
| `matrix[row][col] > target` | 当前数太大，往左走（col--）|
| `matrix[row][col] < target` | 当前数太小，往下走（row++）|
| 每步排除 | 往左排除一列，往下排除一行 |

## 📝 带注释课文
```python
class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        if not matrix or not matrix[0]:
            return False

        m, n = len(matrix), len(matrix[0])
        row = 0          # 从第一行开始
        col = n - 1      # 从最后一列开始（右上角）

        while row < m and col >= 0:
            current = matrix[row][col]
            if current == target:
                return True         # 找到了
            elif current > target:
                col -= 1            # 太大，往左走（排除这一列）
            else:
                row += 1            # 太小，往下走（排除这一行）

        return False  # 走出边界了，说明不存在
```

## 🔄 手动走表
输入 `matrix = [[1,4,7,11],[2,5,8,12],[3,6,9,16],[10,14,17,24]]`，`target = 5`

| 步骤 | (row, col) | matrix[row][col] | 比较 | 操作 |
|------|------------|------------------|------|------|
| 1 | (0, 3) | 11 | 11 > 5 | 往左走 col=2 |
| 2 | (0, 2) | 7 | 7 > 5 | 往左走 col=1 |
| 3 | (0, 1) | 4 | 4 < 5 | 往下走 row=1 |
| 4 | (1, 1) | 5 | 5 == 5 | 找到了！返回 True |

对比：如果 target = 20

| 步骤 | (row, col) | matrix[row][col] | 比较 | 操作 |
|------|------------|------------------|------|------|
| 1 | (0, 3) | 11 | 11 < 20 | 往下 row=1 |
| 2 | (1, 3) | 12 | 12 < 20 | 往下 row=2 |
| 3 | (2, 3) | 16 | 16 < 20 | 往下 row=3 |
| 4 | (3, 3) | 24 | 24 > 20 | 往左 col=2 |
| 5 | (3, 2) | 17 | 17 < 20 | 往下 row=4 → 越界，返回 False |

## ⚠️ 易错点
- 起点**必须是右上角**（或左下角），不能是左上角或右下角——左上角往右和往下都变大，无法决策方向
- 从左下角出发也可以：比目标大就往上走（row--），比目标小就往右走（col++）
- 循环条件 `row < m and col >= 0` 必须同时检查行和列越界
- 时间复杂度 O(m+n)，不是 O(log(m×n))，因为每步只排除一行或一列，不是对半分
