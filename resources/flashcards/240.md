# 240 搜索二维矩阵II

## 标签
矩阵

## 核心思路
从矩阵的右上角（或左下角）开始搜索。以右上角为例：当前元素比 target 大则左移（列变小），比 target 小则下移（行变大）。每步排除一行或一列，时间 O(m+n)。

## 代码模板
```python
class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        if not matrix or not matrix[0]:
            return False

        m, n = len(matrix), len(matrix[0])
        # 从右上角开始
        row, col = 0, n - 1

        while row < m and col >= 0:
            current = matrix[row][col]

            if current == target:
                return True
            elif current > target:
                col -= 1  # 当前值太大，向左移（列减小）
            else:
                row += 1  # 当前值太小，向下移（行增大）

        return False
```

### 为什么从右上角开始？
```
矩阵特性：每行从左到右递增，每列从上到下递增

右上角的元素：
  - 它是所在行的最大值
  - 它是所在列的最小值

因此：
  - target < 当前值 → 当前列下方更大，排除整列，左移
  - target > 当前值 → 当前行左边更小，排除整行，下移
```

### 左下角版本
```python
class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        if not matrix or not matrix[0]:
            return False

        m, n = len(matrix), len(matrix[0])
        # 从左下角开始
        row, col = m - 1, 0

        while row >= 0 and col < n:
            current = matrix[row][col]

            if current == target:
                return True
            elif current > target:
                row -= 1  # 太大，上移
            else:
                col += 1  # 太小，右移

        return False
```

## 关键点
- 从右上角或左下角出发，这两个角是"决策点"
- 右上角：行最大、列最小，比较后可排除一行或一列
- 每步缩小搜索范围，总共最多 m+n 步

## 易错点
- 不能从左上角或右下角开始：这两角无法决定移动方向
- 边界条件：`row < m and col >= 0`（右上角），不能越界
- 空矩阵要先判断
