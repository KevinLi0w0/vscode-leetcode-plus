# 438 找到字符串中所有字母异位词

## 📖 故事
在文稿里找一个定长的窗口滑过去，看窗口里字母的"成分"和目标词是否一致。就像检查每一页纸上的字母出现次数是否和目标页一样——只比较26个字母的计数。

## 🗣️ 人话对照表
| 代码里的 | 人话 |
|----------|------|
| pCount | 目标词的字母成分表（26格） |
| sCount | 窗口内的字母成分表（26格） |
| len | 目标词长度，也是窗口宽度 |
| result | 记录所有符合的窗口起点 |

## 📝 带注释课文
```python
class Solution:
    def findAnagrams(self, s: str, p: str) -> List[int]:
        # 目标串比源串还长，不可能有解
        ns, np = len(s), len(p)
        if ns < np:
            return []

        pCount = [0] * 26  # 目标串的字母计数
        sCount = [0] * 26   # 窗口内的字母计数
        result = []

        # 先统计目标串 p 的字母频率
        for ch in p:
            pCount[ord(ch) - ord('a')] += 1

        # 滑动窗口遍历 s
        for i in range(ns):
            # 右边新进来一个字符，对应计数+1
            sCount[ord(s[i]) - ord('a')] += 1

            # 窗口左边该踢出去一个字符了（i >= np 才有完整的窗口）
            if i >= np:
                # i - np 就是窗口最左边的位置，把它踢掉
                sCount[ord(s[i - np]) - ord('a')] -= 1

            # 窗口满了（i >= np - 1），比较两个计数表
            if i >= np - 1 and sCount == pCount:
                result.append(i - np + 1)  # 记录窗口起点

        return result
```

## 🔄 手动走表
用 `s = "cbaebabacd"`, `p = "abc"`，np=3

| 步骤 | i | s[i] | sCount | 窗口 | 说明 |
|------|---|------|--------|------|------|
| 0 | 0 | c | [0,0,1,...] | "c" | 加入c，窗口未满 |
| 1 | 1 | b | [0,1,1,...] | "cb" | 加入b，窗口未满 |
| 2 | 2 | a | [1,1,1,...] | "cba" | 加入a，窗口满。sCount==pCount? pCount=[1,1,1,...] 是! 记录起点0 |
| 3 | 3 | e | [1,1,1,0,1,...] | "bae" | 加入e，踢出c(i-np=0)，sCount=[0,1,0,0,1] ≠ pCount |
| 4 | 4 | b | [0,2,0,0,1,...] | "aeb" | 加入b，踢出b(i-np=1)，sCount=[0,1,0,0,1] ≠ pCount |
| 5 | 5 | a | [1,1,0,0,1,...] | "eba" | 加入a，踢出a(i-np=2)，sCount=[1,0,1,0,1] ≠ pCount |
| 6 | 6 | b | [1,1,1,0,1,...] | "bab" | 加入b，踢出e(i-np=3)，sCount=[1,1,1,0,0] ≠ pCount |
| 7 | 7 | a | [2,1,1,...] | "aba" | 加入a，踢出b，sCount=[2,0,1] ≠ pCount |
| 8 | 8 | c | [1,1,1,...] | "bac" | 加入c，踢出b，sCount=[1,0,2] ≠ pCount |
| 9 | 9 | d | [1,1,2,0,0,1,...] | "acd" | 加入d，踢出a，sCount=[0,1,2,...] ≠ pCount |

最终 result = [0]（p="abc" 各1次，只有 "cba" 匹配）

## ⚠️ 易错点
- 窗口踢出字符的条件是 `i >= np`，不是 `i >= np - 1`
- 踢出的位置是 `i - np`，不是 `i - np + 1`
- 比较的是两个长度为26的列表，Python可以直接 `==` 比较
- 起点计算是 `i - np + 1`，即窗口左边界的下标
