# 438 找到字符串中所有字母异位词

## 标签
滑动窗口

## 核心思路
在 s 中维护一个长度为 len(p) 的定长滑动窗口，用两个 26 字母计数数组比较窗口内字符和 p 的字符是否一致。优化：维护一个 `matched` 变量记录字符频次匹配的个数，避免每次比较整个数组。时间 O(n)。

## 代码模板
```python
class Solution:
    def findAnagrams(self, s: str, p: str) -> List[int]:
        if len(s) < len(p):
            return []

        result = []
        p_count = [0] * 26  # p 的字符计数
        s_count = [0] * 26  # 窗口内的字符计数

        # 统计 p 的字符频次
        for ch in p:
            p_count[ord(ch) - ord('a')] += 1

        window_size = len(p)

        for i in range(len(s)):
            # 右端字符进入窗口
            s_count[ord(s[i]) - ord('a')] += 1

            # 左端字符离开窗口（当窗口超过定长时）
            if i >= window_size:
                s_count[ord(s[i - window_size]) - ord('a')] -= 1

            # 窗口大小等于 p 的长度时，比较两个计数数组
            if i >= window_size - 1:
                if s_count == p_count:
                    result.append(i - window_size + 1)

        return result
```

## 关键点
- 定长窗口：窗口大小始终等于 len(p)
- 用数组计数比排序更高效
- 逐个字符进出窗口，避免每次重新统计

## 易错点
- 当 `i >= window_size` 时才需要移除左端字符
- 比较窗口的时机是 `i >= window_size - 1`（窗口刚好满）
- 注意 len(s) < len(p) 时直接返回空列表
