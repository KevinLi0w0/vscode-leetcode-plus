# 189 轮转数组

## 标签
普通数组

## 核心思路
三次反转法：先将 `k` 取模（`k %= n`），然后反转整个数组，再分别反转前 k 个和后 n-k 个元素。三次反转均为 O(n) 原地操作，总时间 O(n)，空间 O(1)。

## 代码模板
```python
class Solution:
    def rotate(self, nums: List[int], k: int) -> None:
        """
        Do not return anything, modify nums in-place instead.
        """
        n = len(nums)
        k = k % n  # 处理 k > n 的情况

        # 辅助反转函数
        def reverse(start, end):
            while start < end:
                nums[start], nums[end] = nums[end], nums[start]
                start += 1
                end -= 1

        # 第一步：反转整个数组
        reverse(0, n - 1)

        # 第二步：反转前 k 个元素
        reverse(0, k - 1)

        # 第三步：反转后 n-k 个元素
        reverse(k, n - 1)
```

### 示例
```
原数组: [1,2,3,4,5,6,7], k=3
反转全部: [7,6,5,4,3,2,1]
反转前3个: [5,6,7,4,3,2,1]
反转后4个: [5,6,7,1,2,3,4]  ← 结果
```

## 关键点
- `k %= n` 必不可少，否则 k 超过数组长度会出错
- 三次反转的顺序：整体 → 前k → 后n-k
- 原地操作，不需要额外数组

## 易错点
- 忘记 `k %= n`，当 k >= n 时结果错误
- 反转函数的参数是下标范围 [start, end]，包含两端
- 题目要求原地修改，不能用切片赋值 `nums[:] = nums[n-k:] + nums[:n-k]`（虽能 AC 但非真正 O(1)）
