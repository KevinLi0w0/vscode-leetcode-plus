# 189 轮转数组

## 📖 故事
一排人向右轮转 k 步。有个翻转魔术：先全部翻转，再把前 k 个翻回来，再把后面翻回来——就像先倒着念，再正着念两半。三次翻转，原地完成，不需要额外空间。

## 🗣️ 人话对照表
| 代码里的 | 人话 |
|----------|------|
| k %= n | k 可能比 n 大，取余 |
| reverse(nums, 0, n-1) | 全部翻转 |
| reverse(nums, 0, k-1) | 翻回前 k 个 |
| reverse(nums, k, n-1) | 翻回后 n-k 个 |

## 📝 带注释课文
```python
class Solution:
    def rotate(self, nums: List[int], k: int) -> None:
        n = len(nums)
        k = k % n  # k 可能远大于 n，取余后才是有效轮转次数

        # 辅助函数：翻转 nums 的 [start, end] 区间
        def reverse(start, end):
            while start < end:
                nums[start], nums[end] = nums[end], nums[start]
                start += 1
                end -= 1

        reverse(0, n - 1)   # 第1次：全部翻转
        reverse(0, k - 1)   # 第2次：翻回前 k 个
        reverse(k, n - 1)   # 第3次：翻回后 n-k 个
```

## 🔄 手动走表
用 `nums = [1, 2, 3, 4, 5, 6, 7]`, `k = 3`，k%n=3

| 步骤 | 操作 | nums 状态 | 说明 |
|------|------|-----------|------|
| 0 | 初始 | [1, 2, 3, 4, 5, 6, 7] | - |
| 1 | 全部翻转 | [7, 6, 5, 4, 3, 2, 1] | reverse(0, 6) |
| 2 | 翻回前3个 | [5, 6, 7, 4, 3, 2, 1] | reverse(0, 2) |
| 3 | 翻回后4个 | [5, 6, 7, 1, 2, 3, 4] | reverse(3, 6) |

最终 nums = [5, 6, 7, 1, 2, 3, 4] — 原来最后3个 [5,6,7] 移到了前面

## ⚠️ 易错点
- `k %= n` 必须放在最前面，否则 k > n 时会越界出错
- 翻转的区间是**闭区间**，`reverse(0, k-1)` 不是 `reverse(0, k)`
- 三次翻转的顺序不能变：先全部翻，再两段分别翻
- 如果 k=0，三次翻转都不会动，结果不变（正确）
- 这是原地修改，不需要返回值
