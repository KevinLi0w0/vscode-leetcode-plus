# 11 盛最多水的容器

## 标签
双指针

## 核心思路
用左右双指针从两端向内收缩。面积由较矮的一端和两指针的距离决定。移动较矮的一端才有可能增大面积（因为宽度在缩小，只有增加高度才有可能补偿）。每次移动较矮端，记录最大面积。时间 O(n)。

## 代码模板
```python
class Solution:
    def maxArea(self, height: List[int]) -> int:
        left, right = 0, len(height) - 1  # 左右双指针
        max_area = 0

        while left < right:
            # 面积 = 较矮的高度 × 宽度
            h = min(height[left], height[right])
            w = right - left
            max_area = max(max_area, h * w)

            # 移动较矮的一端，因为只有提高较矮端才可能增大面积
            if height[left] < height[right]:
                left += 1
            else:
                right -= 1

        return max_area
```

## 关键点
- 面积 = min(左高度, 右高度) × 宽度
- 每次移动较矮的一端：宽度在缩小，只有提升较矮端高度才可能增大面积
- 不需要回溯：较高端不动不会丢失最优解

## 易错点
- 移动较高端一定不会得到更大面积，所以无需考虑
- 当两端等高时，移动哪边都可以，不影响正确性
- 不要在移动前/后搞混宽度的计算位置
