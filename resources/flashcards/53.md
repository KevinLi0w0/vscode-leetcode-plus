# 53 最大子数组和

## 标签
普通数组

## 核心思路
Kadane 算法：`dp[i]` 表示以 `nums[i]` 结尾的最大子数组和。状态转移为 `dp[i] = max(nums[i], dp[i-1] + nums[i])`——要么把当前数接在前面的子数组后面，要么从当前数重新开始。空间优化用单个变量即可。时间 O(n)。

## 代码模板
```python
class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        # current_max: 以当前元素结尾的最大子数组和
        # global_max: 全局最大子数组和
        current_max = global_max = nums[0]

        for i in range(1, len(nums)):
            # 要么接在前面子数组后面，要么从当前元素重新开始
            current_max = max(nums[i], current_max + nums[i])

            # 更新全局最大值
            global_max = max(global_max, current_max)

        return global_max
```

### 前缀和版本
```python
class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        prefix_sum = 0
        min_prefix = 0  # 维护最小的前缀和
        result = float('-inf')

        for num in nums:
            prefix_sum += num
            result = max(result, prefix_sum - min_prefix)
            min_prefix = min(min_prefix, prefix_sum)

        return result
```

## 关键点
- Kadane 核心思想：如果前面的累计和为负，不如从当前重新开始
- `current_max = max(nums[i], current_max + nums[i])` 是核心转移方程
- 空间优化：只用一个变量代替 dp 数组

## 易错点
- 初始化要用 `nums[0]`，不能用 0（数组可能有全负数）
- `current_max` 是"以当前元素结尾"的最大和，不是全局最大
- 子数组必须连续，与子序列问题不同
