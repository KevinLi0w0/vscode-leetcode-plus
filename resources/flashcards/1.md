# 1 两数之和

## 核心思路
用哈希表在一次遍历中记录已经出现过的 value→index 映射。对每个数 `num`，检查 `complement = target - num` 是否已在哈希表中，若在则直接返回两个下标。一次遍历即可完成，时间复杂度 O(n)。

## 代码模板
```python
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        # 哈希表：存储 值 -> 下标 的映射
        num_to_index = {}

        # 一次遍历，保证每个数只与之前出现过的数配对
        for i, num in enumerate(nums):
            complement = target - num  # 计算需要的补数

            # 如果补数已经在表中，说明找到答案
            if complement in num_to_index:
                return [num_to_index[complement], i]

            # 当前数入表，供后续数查找
            num_to_index[num] = i

        return []  # 题目保证有解，这行不会执行
```

## 关键点
- 哈希表存 value→index 映射，查找 O(1)
- 只需一次遍历：当前数与之前所有数配对即可覆盖全部情况
- 先查表再入表，避免同一元素被使用两次

## 易错点
- 必须先查后存，否则当 `target = 2 * num` 时会把自己配对进去
- 题目保证恰好有一个解，无需考虑无解或多解
- 返回的是下标，不是值
