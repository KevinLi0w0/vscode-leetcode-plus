# 1 两数之和

## 📖 故事
在联谊会上，你想找两个身高加起来刚好等于 target 的人。你拿着名单从头到尾走，每碰到一个人就先问："我要找的另一半（target - 你）你之前见过吗？"如果见过，直接把那两个人拉出来；如果没见过，就把这个人记在花名册上继续走。

## 🗣️ 人话对照表
| 代码里的 | 人话 |
|----------|------|
| `num_to_index` | 花名册：记住了"值→在第几个位置" |
| `complement` | 我要找的另一半：target 减当前人的值 |
| `complement in num_to_index` | 之前见过这个另一半吗？ |
| 先查后存 | 先问再记，防止把自己配给自己 |

## 📝 带注释课文
```python
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        # 花名册：值 -> 下标，记录之前走过的每个人
        num_to_index = {}

        # 逐个遍历名单上的人
        for i, num in enumerate(nums):
            # 算出我需要的另一半是多少
            complement = target - num

            # 先问：这个另一半之前出现过吗？
            if complement in num_to_index:
                # 出现过！就是他，直接返回两个人的位置
                return [num_to_index[complement], i]

            # 没出现，把当前人记入花名册，供后面的人查
            num_to_index[num] = i

        return []  # 题目保证有解，走不到这
```

## 🔄 手动走表
`nums = [2, 7, 11, 15]`, `target = 9`

| 步骤 | i | num | complement | 花名册 | 命中？ |
|------|---|-----|------------|--------|--------|
| 1 | 0 | 2 | 7 | {} | 否，存入 {2:0} |
| 2 | 1 | 7 | 2 | {2:0} | 是！2在花名册中，位置0 |

→ 返回 `[0, 1]`

## ⚠️ 易错点
- 必须先查后存，否则当 `target = 2 * num` 时会把自己配给自己
- 返回的是下标，不是值
- 题目保证恰好一个解，无需考虑无解
