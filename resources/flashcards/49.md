# 49 字母异位词分组

## 📖 故事
老师在整理学生名单，要把"名字用到的字母一模一样、只是顺序不同"的人分到一组。方法是让每个人把自己的名字字母按 a-z 排好作为"组号"，组号相同的分到同一桌。

## 🗣️ 人话对照表
| 代码里的 | 人话 |
|----------|------|
| `sorted(s)` | 把名字字母重新排好队，当作"组号" |
| `''.join(sorted(s))` | 排好后拼成字符串当 key |
| `groups[key]` | 同一组号的那桌人 |
| `defaultdict(list)` | 自动开桌：没桌号就自动开一桌 |

## 📝 带注释课文
```python
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        # 自动开桌的字典：key 是组号，value 是那桌所有人
        groups = collections.defaultdict(list)

        for s in strs:
            # 把名字字母排好队，当作组号
            # eat -> aet, tea -> aet, ate -> aet → 同桌
            key = ''.join(sorted(s))
            groups[key].append(s)

        # 把每桌的人列出来
        return list(groups.values())
```

## 🔄 手动走表
`strs = ["eat", "tea", "tan", "ate", "nat", "bat"]`

| 步骤 | 原字符串 | 排序后key | groups 变化 |
|------|----------|-----------|-------------|
| 1 | eat | aet | {"aet": ["eat"]} |
| 2 | tea | aet | {"aet": ["eat","tea"]} |
| 3 | tan | ant | {"aet": ["eat","tea"], "ant": ["tan"]} |
| 4 | ate | aet | {"aet": ["eat","tea","ate"], "ant": ["tan"]} |
| 5 | nat | ant | {"aet": [...3个], "ant": ["tan","nat"]} |
| 6 | bat | abt | {"aet": [...], "ant": [...2个], "abt": ["bat"]} |

→ 返回 `[["eat","tea","ate"], ["tan","nat"], ["bat"]]`

## ⚠️ 易错点
- `sorted(s)` 返回列表，要 `''.join()` 拼成字符串才能当 key
- 用 `defaultdict(list)` 比手动判断 key 是否存在更简洁
- 返回类型是 `List[List[str]]`，不是 List[str]
