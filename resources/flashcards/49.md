# 49 字母异位词分组

## 核心思路
字母异位词是指字母组成完全相同、仅排列不同的字符串。将每个字符串排序后的结果作为哈希表的 key，原字符串归入同一组。也可以用 26 个字母的计数元组作为 key，避免排序的 O(k log k) 开销，降为 O(k)。

## 代码模板
```python
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        # 哈希表：key 为排序后的字符串，value 为该组的所有原字符串
        groups = collections.defaultdict(list)

        for s in strs:
            # 排序后的字符串作为 key，字母异位词排序后相同
            key = ''.join(sorted(s))
            groups[key].append(s)

        return list(groups.values())
```

### 计数数组版本（更快）
```python
class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        groups = collections.defaultdict(list)

        for s in strs:
            # 用 26 字母计数元组作 key，避免排序
            count = [0] * 26
            for ch in s:
                count[ord(ch) - ord('a')] += 1
            groups[tuple(count)].append(s)

        return list(groups.values())
```

## 关键点
- 字母异位词的核心特征：字母组成相同
- 排序 key 简单直观，计数 key 更快 O(k)
- 元组（tuple）可作为哈希表的 key，列表不行

## 易错点
- defaultdict(list) 比手动判断 key 是否存在更简洁
- 计数数组必须转成 tuple 才能作为 key
- 返回值是 List[List[str]]，注意类型
