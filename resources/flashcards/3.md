# 3 无重复字符的最长子串

## 标签
滑动窗口

## 核心思路
用滑动窗口维护一个无重复字符的子串。右指针不断扩展，当遇到重复字符时，左指针收缩到重复字符的下一个位置。用哈希表记录每个字符的最新下标，实现 O(1) 跳转。时间 O(n)。

## 代码模板
```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        # 哈希表：记录每个字符最近一次出现的下标
        char_index = {}
        left = 0  # 滑动窗口左边界
        max_len = 0

        for right, ch in enumerate(s):
            # 如果字符已在窗口内（下标 >= left），左边界跳到其下一位
            if ch in char_index and char_index[ch] >= left:
                left = char_index[ch] + 1

            # 更新字符的最新下标
            char_index[ch] = right

            # 更新最大长度
            max_len = max(max_len, right - left + 1)

        return max_len
```

## 关键点
- 哈希表存字符→下标，遇到重复可直接把 left 跳到正确位置
- 必须判断 `char_index[ch] >= left`：字符可能在窗口外，不算重复
- left 跳跃而非逐步移动，保证 O(n) 时间

## 易错点
- 忘记判断 `char_index[ch] >= left`，导致 left 回退到更小的值
- 更新 char_index 和 max_len 的顺序不能乱
- 空字符串返回 0
