# 3 无重复字符的最长子串

## 📖 故事
滑动窗口像一条毛毛虫趴在字符串上。右边不断吃新字符，一旦吃到肚子里已有的字符，左边就赶紧吐到重复字符后面为止。随时记录身长最长的时刻。

## 🗣️ 人话对照表
| 代码里的 | 人话 |
|----------|------|
| `right` | 毛毛虫的头，不断往右吃 |
| `left` | 毛毛虫的尾巴，遇到重复就往右缩 |
| `char_index` | 记账本：每个字符上次出现在哪 |
| `char_index[ch] >= left` | 这个字符在窗口（身体）内吗？ |
| `right - left + 1` | 当前身长 |

## 📝 带注释课文
```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        # 记账本：字符 -> 上次出现的下标
        char_index = {}
        left = 0       # 毛毛虫尾巴
        max_len = 0    # 最长身长记录

        for right, ch in enumerate(s):
            # 吃到重复字符了？但要确认它在身体（窗口）内
            # 如果 char_index[ch] < left，说明在尾巴外面，不算重复
            if ch in char_index and char_index[ch] >= left:
                # 尾巴跳到重复字符的下一个位置，把重复那个吐掉
                left = char_index[ch] + 1

            # 更新记账本：当前字符的最新位置
            char_index[ch] = right

            # 记录当前身长
            max_len = max(max_len, right - left + 1)

        return max_len
```

## 🔄 手动走表
`s = "abcabcbb"`

| 步骤 | right | ch | char_index[ch] | 在窗口内? | left | 窗口 | max_len |
|------|-------|-----|----------------|-----------|------|------|---------|
| 1 | 0 | a | 无 | — | 0 | "a" | 1 |
| 2 | 1 | b | 无 | — | 0 | "ab" | 2 |
| 3 | 2 | c | 无 | — | 0 | "abc" | 3 |
| 4 | 3 | a | 0 | 0≥0 是 | 1 | "bca" | 3 |
| 5 | 4 | b | 1 | 1≥1 是 | 2 | "cab" | 3 |
| 6 | 5 | c | 2 | 2≥2 是 | 3 | "abc" | 3 |
| 7 | 6 | b | 4 | 4≥3 是 | 5 | "cb" | 3 |
| 8 | 7 | b | 6 | 6≥5 是 | 7 | "b" | 3 |

→ 返回 `3`

## ⚠️ 易错点
- 必须判断 `char_index[ch] >= left`：字符可能在窗口外，不跳的话 left 会回退
- 更新 `char_index[ch] = right` 在 `left` 调整之后，不能反过来
- 空字符串返回 0，`max_len` 初始值就是 0 没问题
