# 48 旋转图像

## 标签
矩阵

## 核心思路
顺时针旋转 90° = 沿主对角线转置 + 每行左右翻转。转置使得行变列，翻转使得左右顺序调换。两步均为原地操作，时间 O(n²)，空间 O(1)。

## 代码模板
```python
class Solution:
    def rotate(self, matrix: List[List[int]]) -> None:
        """
        Do not return anything, modify matrix in-place instead.
        """
        n = len(matrix)

        # 第一步：沿主对角线转置（matrix[i][j] 与 matrix[j][i] 交换）
        # 只遍历上三角，避免交换两次
        for i in range(n):
            for j in range(i + 1, n):
                matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]

        # 第二步：每行左右翻转
        for i in range(n):
            matrix[i].reverse()
```

### 示例
```
原矩阵:
  [1, 2, 3]
  [4, 5, 6]
  [7, 8, 9]

转置后:
  [1, 4, 7]
  [2, 5, 8]
  [3, 6, 9]

每行翻转后:
  [7, 4, 1]
  [8, 5, 2]
  [9, 6, 3]  ← 顺时针旋转90°的结果
```

## 关键点
- 顺时针 90° = 转置 + 行翻转
- 逆时针 90° = 转置 + 列翻转
- 转置只需遍历上三角（`j` 从 `i+1` 开始）

## 易错点
- 转置时只遍历 `j > i` 的部分，否则会交换两次等于没变
- `matrix[i].reverse()` 是原地操作
- 旋转方向不同则操作组合不同
