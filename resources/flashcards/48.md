# 48 旋转图像

## 📖 故事
把一张方形照片顺时针转90度有个巧妙办法：先沿主对角线翻转（像合上一本书），再每行左右翻转（像翻煎饼）。两步搞定，不需要额外空间。

## 🗣️ 人话对照表
| 代码里的 | 人话 |
|----------|------|
| 转置 `matrix[i][j] ↔ matrix[j][i]` | 沿对角线翻转，行变列、列变行 |
| `row.reverse()` | 每行左右翻转 |
| 两步合起来 | 转置 + 行翻转 = 顺时针90度 |

## 📝 带注释课文
```python
class Solution:
    def rotate(self, matrix: List[List[int]]) -> None:
        n = len(matrix)

        # 第一步：沿主对角线转置
        # matrix[i][j] 和 matrix[j][i] 互换
        for i in range(n):
            for j in range(i + 1, n):  # j 从 i+1 开始，只处理上三角，避免互换两次
                matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]

        # 第二步：每行左右翻转
        for row in matrix:
            row.reverse()  # 原地翻转这一行
```

## 🔄 手动走表
输入 `matrix = [[1,2,3],[4,5,6],[7,8,9]]`

**第一步：转置**

| 交换 | 交换前 | 交换后 |
|------|--------|--------|
| (0,1)↔(1,0) | 2↔4 | [[1,4,3],[2,5,6],[7,8,9]] |
| (0,2)↔(2,0) | 3↔7 | [[1,4,7],[2,5,6],[3,8,9]] |
| (1,2)↔(2,1) | 6↔8 | [[1,4,7],[2,5,8],[3,6,9]] |

转置后: `[[1,4,7],[2,5,8],[3,6,9]]`

**第二步：每行翻转**

| 行 | 翻转前 | 翻转后 |
|----|--------|--------|
| 0 | [1,4,7] | [7,4,1] |
| 1 | [2,5,8] | [8,5,2] |
| 2 | [3,6,9] | [9,6,3] |

最终 `matrix = [[7,4,1],[8,5,2],[9,6,3]]`

## ⚠️ 易错点
- 转置时内层循环 `j` 从 `i+1` 开始，不是 `0`。如果从0开始会交换两次等于没换
- 顺时针90度 = 转置 + 行翻转；逆时针90度 = 转置 + 列翻转
- `row.reverse()` 是原地操作，不需要赋值返回
- 如果用 `matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]` 交换，Python 的元组交换保证是原子的，不会中间出错
