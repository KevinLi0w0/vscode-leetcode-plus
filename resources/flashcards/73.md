# 73 矩阵置零

## 📖 故事
教室座位矩阵里，某个位置的人作弊，整行整列都要记过清零。但不能直接改（会连锁反应，改了之后就分不清谁原本是0了）。所以用第一排和第一列当"记事本"，先标记哪些行列要清零，最后统一处理。

## 🗣️ 人话对照表
| 代码里的 | 人话 |
|----------|------|
| `matrix[0][j] = 0` | 第一行记事本：第 j 列要清零 |
| `matrix[i][0] = 0` | 第一列记事本：第 i 行要清零 |
| `firstRowZero` | 第一行自己要不要清零（额外变量） |
| `firstColZero` | 第一列自己要不要清零（额外变量） |
| 最后两遍扫描 | 根据记事本统一清零 |

## 📝 带注释课文
```python
class Solution:
    def setZeroes(self, matrix: List[List[int]]) -> None:
        m, n = len(matrix), len(matrix[0])
        firstRowZero = False  # 记录第一行本身是否需要清零
        firstColZero = False  # 记录第一列本身是否需要清零

        # 检查第一行是否有0
        for j in range(n):
            if matrix[0][j] == 0:
                firstRowZero = True
                break

        # 检查第一列是否有0
        for i in range(m):
            if matrix[i][0] == 0:
                firstColZero = True
                break

        # 用第一行第一列当记事本，标记哪些行列要清零
        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][j] == 0:
                    matrix[i][0] = 0   # 第 i 行要清零
                    matrix[0][j] = 0   # 第 j 列要清零

        # 根据记事本清零内部区域（不包括第一行第一列）
        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][0] == 0 or matrix[0][j] == 0:
                    matrix[i][j] = 0

        # 最后处理第一行
        if firstRowZero:
            for j in range(n):
                matrix[0][j] = 0

        # 最后处理第一列
        if firstColZero:
            for i in range(m):
                matrix[i][0] = 0
```

## 🔄 手动走表
输入 `matrix = [[1,1,1],[1,0,1],[1,1,1]]`

| 步骤 | 操作 | matrix 状态 | 说明 |
|------|------|-------------|------|
| 1 | 检查第一行 | 不变 | 第一行无0，firstRowZero=False |
| 2 | 检查第一列 | 不变 | 第一列无0，firstColZero=False |
| 3 | i=1,j=1 | [[1,1,1],[0,0,1],[1,1,1]] | matrix[1][1]=0，标记matrix[1][0]=0,matrix[0][1]=0 |
| 4 | 清零内部 | [[1,0,1],[0,0,0],[1,0,1]] | (1,1)行标记→整行清；(1,2)列标记→整列清 |

最终 `matrix = [[1,0,1],[0,0,0],[1,0,1]]`

## ⚠️ 易错点
- 必须先检查第一行第一列本身是否有0，再用它们当记事本，顺序不能反
- 清零时要先清内部区域（1~m-1, 1~n-1），最后才清第一行第一列
- 如果先清了第一行第一列，记事本信息就丢了，整个矩阵会全变0
- `firstRowZero` 和 `firstColZero` 是必须的额外变量，否则无法区分第一行/列的0是原始的还是标记的
