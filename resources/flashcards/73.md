# 73 矩阵置零

## 标签
矩阵

## 核心思路
要求 O(1) 空间。用第一行和第一列作为标记数组，记录该行/该列是否需要置零。但第一行和第一列本身需要额外用两个变量 `first_row_zero` 和 `first_col_zero` 来记录。先扫描标记，再根据标记置零。

## 代码模板
```python
class Solution:
    def setZeroes(self, matrix: List[List[int]]) -> None:
        """
        Do not modify matrix in-place directly with extra 2D array.
        Use first row and first column as markers.
        """
        m, n = len(matrix), len(matrix[0])
        first_row_zero = False  # 第一行是否需要置零
        first_col_zero = False  # 第一列是否需要置零

        # 第一步：检查第一行和第一列本身是否含0
        for j in range(n):
            if matrix[0][j] == 0:
                first_row_zero = True
                break
        for i in range(m):
            if matrix[i][0] == 0:
                first_col_zero = True
                break

        # 第二步：用第一行第一列做标记
        # 遍历 [1:] 区域，遇到0就把对应的第一行/第一列位置标记为0
        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][j] == 0:
                    matrix[i][0] = 0  # 标记该行需要置零
                    matrix[0][j] = 0  # 标记该列需要置零

        # 第三步：根据标记，将 [1:] 区域置零
        for i in range(1, m):
            for j in range(1, n):
                if matrix[i][0] == 0 or matrix[0][j] == 0:
                    matrix[i][j] = 0

        # 第四步：处理第一行
        if first_row_zero:
            for j in range(n):
                matrix[0][j] = 0

        # 第五步：处理第一列
        if first_col_zero:
            for i in range(m):
                matrix[i][0] = 0
```

## 关键点
- 用第一行第一列做标记，实现 O(1) 空间
- 两个额外变量记录第一行第一列本身的状态
- 先标记后置零，顺序不能反

## 易错点
- 必须先处理 [1:] 区域再处理第一行第一列，否则标记会被破坏
- 第一行和第一列本身含 0 的情况需要单独处理
- 标记和置零的顺序至关重要，否则会误置零
