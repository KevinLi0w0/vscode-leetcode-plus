# 560 和为K的子数组

## 标签
子串

## 核心思路
利用前缀和，将问题转化为：寻找两个前缀和之差等于 k。用哈希表记录每个前缀和出现的次数，对每个位置，查 `prefix - k` 在哈希表中的个数即为以当前位置结尾、和为 k 的子数组数。时间 O(n)。

## 代码模板
```python
class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        # 哈希表：前缀和 -> 出现次数
        prefix_count = {0: 1}  # 前缀和为0出现1次（空前缀）
        current_sum = 0
        count = 0

        for num in nums:
            current_sum += num  # 更新前缀和

            # 如果 current_sum - k 在表中，说明存在子数组和为 k
            count += prefix_count.get(current_sum - k, 0)

            # 当前前缀和入表
            prefix_count[current_sum] = prefix_count.get(current_sum, 0) + 1

        return count
```

## 关键点
- 前缀和差等于 k，即 `prefix[j] - prefix[i] = k`
- 哈希表存前缀和的出现次数，查 `current_sum - k`
- 初始化 `{0: 1}`：表示前缀和为 0 出现一次（从开头开始的子数组）

## 易错点
- 必须初始化 `prefix_count = {0: 1}`，否则会漏掉从索引 0 开始的子数组
- 先查表再入表，保证子数组不以当前位置为起点（前缀和差要求 i < j）
- 本题不能用滑动窗口，因为数组可能有负数，窗口和不是单调的
