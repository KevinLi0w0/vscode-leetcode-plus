# 76 最小覆盖子串

## 标签
子串

## 核心思路
用滑动窗口+计数法。right 指针不断扩展直到窗口包含 t 的所有字符，然后 left 指针收缩以寻找最小窗口。用一个 `formed` 变量记录已满足的字符种类数，避免每次比较整个计数表。时间 O(|s| + |t|)。

## 代码模板
```python
class Solution:
    def minWindow(self, s: str, t: str) -> str:
        if not s or not t or len(s) < len(t):
            return ""

        # 统计 t 中每个字符的需求量
        dict_t = collections.Counter(t)
        required = len(dict_t)  # 需要匹配的字符种类数

        # 滑动窗口的字符计数
        window_count = collections.defaultdict(int)
        formed = 0  # 已满足的字符种类数

        left = 0
        ans = (float('inf'), None, None)  # (窗口长度, 左, 右)

        for right, ch in enumerate(s):
            window_count[ch] += 1

            # 如果该字符在 t 中，且窗口中的数量刚好达到需求，formed 加1
            if ch in dict_t and window_count[ch] == dict_t[ch]:
                formed += 1

            # 当窗口满足条件时，尝试收缩左边界
            while left <= right and formed == required:
                # 更新最小窗口
                if right - left + 1 < ans[0]:
                    ans = (right - left + 1, left, right)

                # 左边界字符离开窗口
                left_ch = s[left]
                window_count[left_ch] -= 1
                if left_ch in dict_t and window_count[left_ch] < dict_t[left_ch]:
                    formed -= 1

                left += 1

        return "" if ans[0] == float('inf') else s[ans[1]:ans[2] + 1]
```

## 关键点
- `formed` 记录已满足的字符种类数，与 `required` 比较判断窗口是否合法
- 双指针：right 扩展找可行解，left 收缩找最优解
- 判断条件是 `window_count[ch] == dict_t[ch]`，刚好相等时 formed 才增加

## 易错点
- formed 增加的条件是"刚好等于"，而不是">="
- formed 减少的条件是"开始小于需求量"
- 收缩时先更新结果再移除左字符，顺序不能反
- 返回的是子串，不是长度
