# 76 最小覆盖子串

## 📖 故事
在大段文字里找最短的一段，把关键词全囊括进去。右指针猛吃字符直到全覆盖，然后左指针使劲缩直到刚不能再缩为止。每次缩到极限就记录一次最短长度——像手风琴一样拉开再合拢。

## 🗣️ 人话对照表
| 代码里的 | 人话 |
|----------|------|
| need | 关键词的字母需求表 {字母: 需要几个} |
| window | 当前窗口已收集的字母表 {字母: 已有几个} |
| cnt | 还差几种字母没凑齐 |
| right | 右指针，猛吃字符 |
| left | 左指针，使劲缩 |
| minLen / start | 最短长度 / 起点位置 |

## 📝 带注释课文
```python
class Solution:
    def minWindow(self, s: str, t: str) -> str:
        need = {}   # 目标词各字母的需求量
        for ch in t:
            need[ch] = need.get(ch, 0) + 1

        window = {}  # 窗口内各字母的持有量
        cnt = len(need)  # 还差几种字母没凑齐
        left = 0
        minLen = float('inf')
        start = 0

        for right in range(len(s)):
            # 右指针吃进一个字符
            ch = s[right]
            if ch in need:
                window[ch] = window.get(ch, 0) + 1
                # 这个字母刚好够了，需求种类减1
                if window[ch] == need[ch]:
                    cnt -= 1

            # 所有字母都凑齐了，开始缩左边
            while cnt == 0:
                # 记录当前窗口长度
                if right - left + 1 < minLen:
                    minLen = right - left + 1
                    start = left

                # 左指针要吐出一个字符
                out = s[left]
                if out in need:
                    if window[out] == need[out]:
                        cnt += 1  # 这个字母从够变成不够了
                    window[out] -= 1
                left += 1

        return "" if minLen == float('inf') else s[start:start + minLen]
```

## 🔄 手动走表
用 `s = "ADOBECODEBANC"`, `t = "ABC"`，need = {A:1, B:1, C:1}, cnt=3

| 步骤 | right | s[right] | window | cnt | left | 操作说明 | minLen/start |
|------|-------|----------|--------|-----|------|----------|--------------|
| 1 | 0 | A | {A:1} | 2 | 0 | A够了，cnt 3→2 | ∞ |
| 2 | 1 | D | {A:1} | 2 | 0 | D不在need | ∞ |
| 3 | 2 | O | {A:1} | 2 | 0 | O不在need | ∞ |
| 4 | 3 | B | {A:1,B:1} | 1 | 0 | B够了，cnt 2→1 | ∞ |
| 5 | 4 | E | {A:1,B:1} | 1 | 0 | E不在need | ∞ |
| 6 | 5 | C | {A:1,B:1,C:1} | 0 | 0 | C够了，cnt 1→0。全覆盖！开始缩 | ∞ |
| 7 | 缩 | - | {A:1,B:1,C:1} | 0→1 | 1 | s[0]=A在need，window[A]==need[A]所以cnt+1，window[A]→0。left→1 | 6/0 → 记录"ADOBEC" |
| 8 | 6 | O | {A:0,B:1,C:1} | 1 | 1 | cnt≠0 不缩 | 6/0 |
| 9 | 7 | D | - | 1 | 1 | - | 6/0 |
| 10 | 8 | E | - | 1 | 1 | - | 6/0 |
| 11 | 9 | B | {B:2} | 1 | 1 | B已有1个再加变2，不触发cnt变化 | 6/0 |
| 12 | 10 | A | {A:1,B:2,C:1} | 0 | 1 | A够了 cnt→0。缩！ | 6/0 |
| 13 | 缩 | - | - | 0→? | 2 | s[1]=D不在need，直接left→2 | 6/0 |
| 14 | 缩 | - | - | 0 | 3 | s[2]=O不在need，left→3 | 6/0 |
| ... | ... | ... | ... | ... | ... | 继续缩到s[5]=C时cnt+1停止 | 10/1 → "DOBECODEBA" 更短? No, 10>6 |

最终覆盖的最短子串是 `"BANC"`（从后续步骤中找到，len=4）

## ⚠️ 易错点
- cnt 减1的条件是 `window[ch] == need[ch]`（恰好够），不是 `>=`
- 缩左边时先判断 `window[out] == need[out]` 再减，顺序反了会漏判
- 缩窗口的 while 条件是 `cnt == 0`，不是 `cnt <= 0`
- 最终没找到要返回空字符串，不是返回 None
- minLen 初始用 `float('inf')` 便于比较
