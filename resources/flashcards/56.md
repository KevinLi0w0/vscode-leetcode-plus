# 56 合并区间

## 标签
普通数组

## 核心思路
将所有区间按左端点排序，这样重叠的区间一定相邻。遍历排序后的区间，如果当前区间的左端点 <= 上一区间的右端点，说明有重叠，合并为 `[左, max(右)]`；否则直接加入结果。时间 O(n log n)。

## 代码模板
```python
class Solution:
    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        if not intervals:
            return []

        # 按左端点排序，使重叠区间相邻
        intervals.sort(key=lambda x: x[0])

        merged = [intervals[0]]  # 用第一个区间初始化结果

        for i in range(1, len(intervals)):
            current = intervals[i]
            last = merged[-1]  # 结果中的最后一个区间

            # 当前区间左端 <= 上一区间右端，说明有重叠
            if current[0] <= last[1]:
                # 合并：右端取两者较大值
                last[1] = max(last[1], current[1])
            else:
                # 无重叠，直接加入
                merged.append(current)

        return merged
```

## 关键点
- 排序是关键：按左端点排序后，重叠区间必定相邻
- 合并时右端取 `max`，因为后一个区间可能完全被前一个包含
- 用 `merged[-1]` 直接修改最后区间，避免反复 append/pop

## 易错点
- 合并条件是 `current[0] <= last[1]`（等于也算重叠，如 [1,4] 和 [4,5]）
- 右端取 max 而非直接用 current[1]，考虑 [1,4] 和 [2,3] 的情况
