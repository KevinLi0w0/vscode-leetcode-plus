# 56 合并区间

## 📖 故事
一堆会议时间段按开始时间排好队，然后从前到后扫：如果下一个会议在上一个还没结束时就开了，就把它们合并成一个更长的会议。否则就开一个新会议段。

## 🗣️ 人话对照表
| 代码里的 | 人话 |
|----------|------|
| intervals | 会议时间段列表 [[开始, 结束], ...] |
| intervals.sort(key=...) | 按开始时间排队 |
| merged[-1] | 当前正在合并的会议段 |
| merged[-1][1] | 当前会议段的结束时间 |
| max(merged[-1][1], iv[1]) | 合并后取较晚的结束时间 |

## 📝 带注释课文
```python
class Solution:
    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        # 按开始时间排序，这样只需和前一个比较
        intervals.sort(key=lambda x: x[0])

        merged = []
        for iv in intervals:
            # 如果 merged 为空，或者当前区间和上一个不重叠
            # 不重叠 = 当前开始 > 上一个结束
            if not merged or iv[0] > merged[-1][1]:
                merged.append(iv)
            else:
                # 重叠了，合并：结束时间取两者较大的
                merged[-1][1] = max(merged[-1][1], iv[1])

        return merged
```

## 🔄 手动走表
用 `intervals = [[1,3], [2,6], [8,10], [15,18]]`（已排序）

| 步骤 | iv | merged | 操作说明 |
|------|----|--------|----------|
| 1 | [1,3] | [[1,3]] | merged空，直接加入 |
| 2 | [2,6] | [[1,6]] | iv[0]=2 ≤ merged[-1][1]=3 重叠！结束取max(3,6)=6 |
| 3 | [8,10] | [[1,6], [8,10]] | iv[0]=8 > merged[-1][1]=6 不重叠，加入 |
| 4 | [15,18] | [[1,6], [8,10], [15,18]] | iv[0]=15 > 10 不重叠，加入 |

最终 merged = [[1,6], [8,10], [15,18]]

## ⚠️ 易错点
- 必须先按**开始时间**排序，否则无法只和前一个比较
- 重叠条件是 `iv[0] <= merged[-1][1]`（等于也算重叠），不重叠是 `iv[0] > merged[-1][1]`
- 合并时结束时间要取 `max`，因为可能新区间被完全包含（如 [1,5] 和 [2,3]）
- `intervals.sort(key=lambda x: x[0])` 是原地排序，不返回新列表
