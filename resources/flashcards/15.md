# 15 三数之和

## 标签
双指针

## 核心思路
先排序，然后固定第一个数 `nums[i]`，用左右双指针在剩余部分找两数之和等于 `-nums[i]`。关键在于去重：固定第一个数时跳过重复值，找到一组解后也要跳过左右指针的重复值。时间 O(n²)。

## 代码模板
```python
class Solution:
    def threeSum(self, nums: List[int]) -> List[List[int]]:
        nums.sort()  # 先排序，便于双指针和去重
        result = []
        n = len(nums)

        for i in range(n - 2):
            # 第一个数去重：跳过与前一个相同的值
            if i > 0 and nums[i] == nums[i - 1]:
                continue

            # 剪枝优化：如果最小的三个数都已超过0，后面不可能有解
            if nums[i] + nums[i + 1] + nums[i + 2] > 0:
                break
            # 如果 nums[i] 加上最大的两个数仍小于0，跳过当前 i
            if nums[i] + nums[n - 2] + nums[n - 1] < 0:
                continue

            left, right = i + 1, n - 1
            target = -nums[i]  # 双指针要找的两数之和

            while left < right:
                current_sum = nums[left] + nums[right]

                if current_sum == target:
                    result.append([nums[i], nums[left], nums[right]])

                    # 找到解后，跳过左右指针的重复值
                    while left < right and nums[left] == nums[left + 1]:
                        left += 1
                    while left < right and nums[right] == nums[right - 1]:
                        right -= 1

                    left += 1
                    right -= 1

                elif current_sum < target:
                    left += 1  # 和太小，左指针右移
                else:
                    right -= 1  # 和太大，右指针左移

        return result
```

## 关键点
- 排序是双指针法和去重的基础
- 三处去重：固定 i 时去重，找到解后左右指针各自去重
- 双指针根据当前和与 target 的比较决定移动方向

## 易错点
- 去重时条件是 `nums[i] == nums[i-1]`，不是 `nums[i] == nums[i+1]`
- 找到解后先去重再移动指针，否则会漏解或重解
- 不要忘了 `left < right` 的越界检查
