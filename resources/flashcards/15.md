# 15 三数之和

## 📖 故事
要从一堆数字里找三个加起来等于 0 的人。先排队（排序），固定第一个人不动，后面两个人面对面走。加多了右边的退一步，加少了左边的进一步。找到一组后还得跳过长得一样的，不能重复上报。

## 🗣️ 人话对照表
| 代码里的 | 人话 |
|----------|------|
| `nums.sort()` | 先排队，从小到大站好 |
| `i` | 第一个人（固定的） |
| `left`, `right` | 第二、第三个人，面对面往中间走 |
| `target = -nums[i]` | 后两人加起来要等于第一个人的"负数" |
| 三处去重 | i 去重、left 去重、right 去重 |

## 📝 带注释课文
```python
class Solution:
    def threeSum(self, nums: List[int]) -> List[List[int]]:
        nums.sort()  # 排队，从小到大
        result = []
        n = len(nums)

        for i in range(n - 2):
            # 第一个人去重：跟上一个一样就跳过
            if i > 0 and nums[i] == nums[i - 1]:
                continue

            # 第二、第三个人面对面
            left, right = i + 1, n - 1
            target = -nums[i]  # 后两人之和要等于这个

            while left < right:
                s = nums[left] + nums[right]

                if s == target:
                    result.append([nums[i], nums[left], nums[right]])

                    # 找到后，跳过 left 的重复值
                    while left < right and nums[left] == nums[left + 1]:
                        left += 1
                    # 跳过 right 的重复值
                    while left < right and nums[right] == nums[right - 1]:
                        right -= 1

                    left += 1
                    right -= 1

                elif s < target:
                    left += 1   # 加少了，左边的进一步
                else:
                    right -= 1  # 加多了，右边的退一步

        return result
```

## 🔄 手动走表
`nums = [-1, 0, 1, 2, -1, -4]` → 排序后 `[-4, -1, -1, 0, 1, 2]`

| 步骤 | i | nums[i] | left | right | nums[l]+nums[r] | target | 判断 | 结果 |
|------|---|---------|------|-------|-----------------|--------|------|------|
| 1 | 0 | -4 | 1 | 5 | -1+2=1 | 4 | <4, left++ | |
| 2 | 0 | -4 | 2 | 5 | -1+2=1 | 4 | <4, left++ | |
| 3 | 0 | -4 | 3 | 5 | 0+2=2 | 4 | <4, left++ | |
| 4 | 0 | -4 | 4 | 5 | 1+2=3 | 4 | <4, left++ | |
| 5 | 0 | -4 | 5 | 5 | — | — | left≥right 停 | |
| 6 | 1 | -1 | 2 | 5 | -1+2=1 | 1 | ==1! 命中 | [-1,-1,2] |
| 7 | 1 | -1 | 3 | 4 | 0+1=1 | 1 | ==1! 命中 | [-1,0,1] |
| 8 | 2 | -1 | — | — | — | — | i去重跳过(同上) | |

→ 返回 `[[-1,-1,2], [-1,0,1]]`

## ⚠️ 易错点
- i 去重条件是 `nums[i] == nums[i-1]`，不是 `nums[i] == nums[i+1]`
- 找到解后先去重再移动指针，否则会漏解或重解
- `left < right` 越界检查不能忘，popwhile 和主 while 都要
