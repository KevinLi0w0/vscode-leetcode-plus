# 128 最长连续序列

## 标签
哈希

## 核心思路
将所有数放入 HashSet 实现 O(1) 查找。关键优化是只从连续序列的"起点"开始计数——即 `num - 1` 不在集合中的数。这样每个数最多被访问两次，总时间复杂度 O(n)。

## 代码模板
```python
class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        # 用集合存储所有数，支持 O(1) 查找
        num_set = set(nums)
        longest = 0

        for num in num_set:
            # 只有当 num 是连续序列的起点时才开始计数
            # num-1 不在集合中，说明 num 是某个序列的最小值
            if num - 1 not in num_set:
                current_num = num
                current_len = 1

                # 不断检查下一个数是否在集合中
                while current_num + 1 in num_set:
                    current_num += 1
                    current_len += 1

                longest = max(longest, current_len)

        return longest
```

## 关键点
- HashSet 是 O(1) 查找的基础
- "只从起点计数"是关键优化，避免重复计数
- 每个数最多被 while 循环访问一次，总时间 O(n)

## 易错点
- 遍历 num_set 而非 nums，避免重复元素导致多次计数
- 不要忘记判断 `num - 1 not in num_set`，否则会退化为 O(n²)
- 题目要求 O(n) 时间，排序 O(n log n) 不满足要求
