# 128 最长连续序列

## 📖 故事
你要在一堆乱的停车号牌里找最长的连续编号。比如有 1,3,100,2,4，你从 1 开始数：1→2→3→4，连续 4 个！但 3 也要数吗？不用，因为 3 不是起点（3 前面有 2）。只有起点（num-1 不存在）才开始数，这样每条链只数一次。

## 🗣️ 人话对照表
| 代码里的 | 人话 |
|----------|------|
| `num_set` | 把所有号牌撒在地上，O(1) 就能查有没有 |
| `num - 1 not in num_set` | 我是起点吗？前面没有人就是起点 |
| `current_num` | 正在数的当前号牌 |
| `current_len` | 这条连续链数了几个了 |
| `longest` | 目前发现最长的连续链 |

## 📝 带注释课文
```python
class Solution:
    def longestConsecutive(self, nums: List[int]) -> int:
        # 号牌撒地上，集合支持 O(1) 查找
        num_set = set(nums)
        longest = 0

        for num in num_set:
            # 关键：只有起点才开始数
            # num-1 不在集合中 → num 是某条链的最小值
            if num - 1 not in num_set:
                current_num = num
                current_len = 1

                # 一直往后数，看 num+1, num+2... 在不在
                while current_num + 1 in num_set:
                    current_num += 1
                    current_len += 1

                # 数完一条链，更新最长记录
                longest = max(longest, current_len)

        return longest
```

## 🔄 手动走表
`nums = [100, 4, 200, 1, 3, 2]`
`num_set = {1, 2, 3, 4, 100, 200}`

| 步骤 | num | num-1 在集合中？ | 是起点？ | 往后数 | current_len | longest |
|------|-----|------------------|----------|--------|-------------|---------|
| 1 | 100 | 99 不在 | 是 | 101不在，停 | 1 | 1 |
| 2 | 4 | 3 在 | 否 | 跳过 | - | 1 |
| 3 | 200 | 199 不在 | 是 | 201不在，停 | 1 | 1 |
| 4 | 1 | 0 不在 | 是 | 2→3→4→5不在，停 | 4 | 4 |
| 5 | 3 | 2 在 | 否 | 跳过 | - | 4 |
| 6 | 2 | 1 在 | 否 | 跳过 | - | 4 |

→ 返回 `4`（序列 1,2,3,4）

## ⚠️ 易错点
- 必须遍历 `num_set` 而非 `nums`，否则重复元素会多次计数
- 判断起点是 `num - 1 not in num_set`，不能漏，否则退化为 O(n²)
- 题目要求 O(n)，排序 O(n log n) 不满足要求
