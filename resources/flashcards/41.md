# 41 缺失的第一个正数

## 标签
普通数组

## 核心思路
要求 O(n) 时间 O(1) 空间。利用原地哈希：把每个值 `v`（满足 `1 <= v <= n`）放到下标 `v-1` 的位置。交换完毕后，再扫描一遍数组，第一个 `nums[i] != i+1` 的位置，答案就是 `i+1`。如果全部匹配则答案是 `n+1`。

## 代码模板
```python
class Solution:
    def firstMissingPositive(self, nums: List[int]) -> int:
        n = len(nums)

        # 原地哈希：把每个合法的正数放到正确位置 (值v放下标v-1)
        for i in range(n):
            # 当 nums[i] 在 [1, n] 范围内，且当前位置不正确时，不断交换
            # 注意：要用 while，因为交换过来的新值可能也需要归位
            while 1 <= nums[i] <= n and nums[nums[i] - 1] != nums[i]:
                # 把 nums[i] 放到下标 nums[i]-1 的位置
                correct_idx = nums[i] - 1
                nums[i], nums[correct_idx] = nums[correct_idx], nums[i]

        # 扫描找第一个不在正确位置的下标
        for i in range(n):
            if nums[i] != i + 1:
                return i + 1

        # 所有 1~n 都在，答案是 n+1
        return n + 1
```

### 示例
```
nums = [3, 4, -1, 1]

交换过程:
  i=0: 3 应在 idx=2 → [−1, 4, 3, 1]
       -1 不合法，停止
  i=1: 4 应在 idx=3 → [−1, 1, 3, 4]
       1 应在 idx=0 → [1, -1, 3, 4]
       -1 不合法，停止
  i=2: 3 已在 idx=2，正确，跳过
  i=3: 4 已在 idx=3，正确，跳过

扫描: nums[1] = -1 ≠ 2，返回 2
```

## 关键点
- 原地哈希：值 v 放到下标 v-1
- 只有值在 [1, n] 范围内的数才需要归位
- 用 while 循环：交换过来的新值可能也需要归位

## 易错点
- 交换条件 `nums[nums[i] - 1] != nums[i]` 防止重复值导致死循环
- 不能用 if 而要用 while，否则交换过来的值可能未归位
- 值超出 [1, n] 范围的数直接跳过，无条件归位
