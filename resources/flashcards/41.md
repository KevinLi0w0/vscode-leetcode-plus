# 41 缺失的第一个正数

## 📖 故事
酒店有一排房间，客人乱坐了，每个人拿着一个号码牌。目标是找到第一个空着的正整数号房间（1, 2, 3...）。做法是让每个客人坐回自己号码对应的房间（号码3的人去房间3），然后走一圈看谁不在——第一个空房间就是答案。

## 🗣️ 人话对照表
| 代码里的 | 人话 |
|----------|------|
| `nums[i]` | 第 i 个客人手里的号码牌 |
| `nums[nums[i]-1]` | 号码牌对应的房间（号码3去下标2） |
| swap 交换 | 让客人坐回自己号码的房间 |
| `nums[i] != nums[nums[i]-1]` | 检查目标房间坐的不是正确的人 |
| 最后一遍扫描 | 走一圈看哪个房间的号码不对 |

## 📝 带注释课文
```python
class Solution:
    def firstMissingPositive(self, nums: List[int]) -> int:
        n = len(nums)

        # 第一阶段：让每个正整数坐回自己的位置
        # 号码 val 应该坐在下标 val-1 的位置
        for i in range(n):
            # 只要当前数字是正整数，且不超过n，且没坐对位置，就交换
            while (nums[i] > 0 and nums[i] <= n
                   and nums[i] != nums[nums[i] - 1]):
                # 把 nums[i] 和它应该在的位置上的数交换
                nums[nums[i] - 1], nums[i] = nums[i], nums[nums[i] - 1]
                # 交换后 nums[i] 换来了新数字，while 继续检查它是否也坐对

        # 第二阶段：扫描找第一个不对的位置
        for i in range(n):
            if nums[i] != i + 1:  # 位置 i 应该坐号码 i+1
                return i + 1       # 不对就说明这个正整数缺失了

        # 1 到 n 都在，那缺失的就是 n+1
        return n + 1
```

## 🔄 手动走表
输入 `nums = [3, 4, -1, 1]`，n=4

| 步骤 | i | nums[i] | 操作 | nums 状态 | 说明 |
|------|---|---------|------|-----------|------|
| 1 | 0 | 3 | swap(0, 2) | [-1, 4, 3, 1] | 3应该坐下标2，和-1交换 |
| 2 | 0 | -1 | 跳过 | [-1, 4, 3, 1] | -1不是正整数，停 |
| 3 | 1 | 4 | swap(1, 3) | [-1, 1, 3, 4] | 4应该坐下标3，和1交换 |
| 4 | 1 | 1 | swap(1, 0) | [1, -1, 3, 4] | 1应该坐下标0，和-1交换 |
| 5 | 1 | -1 | 跳过 | [1, -1, 3, 4] | -1不是正整数，停 |
| 6 | 2 | 3 | 已对 | [1, -1, 3, 4] | 3在下标2，正确，停 |
| 7 | 3 | 4 | 已对 | [1, -1, 3, 4] | 4在下标3，正确，停 |

**扫描阶段:**

| i | nums[i] | i+1 | 结果 |
|----|---------|-----|------|
| 0 | 1 | 1 | ✓ |
| 1 | -1 | 2 | ✗ → 返回 2 |

返回 `2`

## ⚠️ 易错点
- 交换时必须用 `while` 而不是 `if`，因为换来的新数字可能也需要归位
- 交换的目标位置是 `nums[i] - 1`（号码3坐下标2），不是 `i - 1`
- 交换条件要检查 `nums[i] != nums[nums[i]-1]`，否则相同值会死循环
- 负数和超过 n 的数直接跳过，它们不属于 1~n 的范围
