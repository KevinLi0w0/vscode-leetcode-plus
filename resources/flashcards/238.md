# 238 除自身以外数组的乘积

## 标签
普通数组

## 核心思路
要求不用除法且 O(n)。先从左到右遍历，`result[i]` 存储当前位置左侧所有元素的乘积（前缀乘积）。再从右到左遍历，用一个变量 `right_product` 累积右侧乘积并乘入 `result[i]`。两次遍历完成。空间 O(1)（不算输出数组）。

## 代码模板
```python
class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        n = len(nums)
        result = [1] * n

        # 第一遍：从左到右，result[i] = 左侧所有元素的乘积
        left_product = 1
        for i in range(n):
            result[i] = left_product  # result[i] 存左侧乘积
            left_product *= nums[i]   # 更新左侧乘积（供下一个位置使用）

        # 第二遍：从右到左，乘上右侧所有元素的乘积
        right_product = 1
        for i in range(n - 1, -1, -1):
            result[i] *= right_product  # 乘上右侧乘积
            right_product *= nums[i]    # 更新右侧乘积（供左边的位置使用）

        return result
```

### 示例
```
nums = [1, 2, 3, 4]

第一遍（左侧乘积）:
  result = [1, 1, 2, 6]

第二遍（乘右侧乘积）:
  i=3: result[3] = 6*1 = 6,  right = 4
  i=2: result[2] = 2*4 = 8,  right = 12
  i=1: result[1] = 1*12 = 12, right = 24
  i=0: result[0] = 1*24 = 24, right = 24

result = [24, 12, 8, 6]
```

## 关键点
- 两次遍历：先填左侧乘积，再乘右侧乘积
- `left_product` 和 `right_product` 是滚动更新的累积乘积
- 不用除法，处理含 0 的情况也没问题

## 易错点
- 第一遍遍历时先赋值再更新 left_product，不能反过来
- 第二遍遍历方向是从右到左
- 结果数组的初始值 `[1] * n`，不能初始化为 0
