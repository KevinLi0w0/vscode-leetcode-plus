# 54 螺旋矩阵

## 📖 故事
走迷宫一样从左上角出发：沿上边走到头就右转，右边走到头再转往下，下边走到头转左，左边走到头转上。每走完一条边就把那条边界往内缩一格，直到把所有格子都走完。

## 🗣️ 人话对照表
| 代码里的 | 人话 |
|----------|------|
| `top` | 当前最上面一行的下标 |
| `bottom` | 当前最下面一行的下标 |
| `left` | 当前最左一列的下标 |
| `right` | 当前最右一列的下标 |
| `result` | 螺旋走一圈收集的所有数 |
| 边界收缩 | top++, bottom--, left++, right-- |

## 📝 带注释课文
```python
class Solution:
    def spiralOrder(self, matrix: List[List[int]]) -> List[int]:
        result = []
        if not matrix:
            return result

        top, bottom = 0, len(matrix) - 1
        left, right = 0, len(matrix[0]) - 1

        while top <= bottom and left <= right:
            # 1. 上边：从左到右
            for j in range(left, right + 1):
                result.append(matrix[top][j])
            top += 1  # 上边走完了，往下缩一格

            # 2. 右边：从上到下
            for i in range(top, bottom + 1):
                result.append(matrix[i][right])
            right -= 1  # 右边走完了，往左缩一格

            # 3. 下边：从右到左（要先检查 top <= bottom）
            if top <= bottom:
                for j in range(right, left - 1, -1):
                    result.append(matrix[bottom][j])
                bottom -= 1  # 下边走完了，往上缩一格

            # 4. 左边：从下到上（要先检查 left <= right）
            if left <= right:
                for i in range(bottom, top - 1, -1):
                    result.append(matrix[i][left])
                left += 1  # 左边走完了，往右缩一格

        return result
```

## 🔄 手动走表
输入 `matrix = [[1,2,3],[4,5,6],[7,8,9]]`

初始: top=0, bottom=2, left=0, right=2

| 步骤 | 方向 | 走过的格子 | 收集 | 收缩后边界 |
|------|------|-----------|------|-----------|
| 1 | 上边→ | 1,2,3 | [1,2,3] | top=1 |
| 2 | 右边↓ | 6,9 | [1,2,3,6,9] | right=1 |
| 3 | 下边← | 8,7 | [1,2,3,6,9,8,7] | bottom=1 |
| 4 | 左边↑ | 4 | [1,2,3,6,9,8,7,4] | left=1 |
| 5 | 上边→ | 5 | [1,2,3,6,9,8,7,4,5] | top=2 |

最终 `result = [1,2,3,6,9,8,7,4,5]`

## ⚠️ 易错点
- 下边和左边走之前必须检查 `top <= bottom` / `left <= right`，否则会重复收集
- 下边是从右往左走（`range(right, left-1, -1)`），方向别搞反
- 左边是从下往上走（`range(bottom, top-1, -1)`），方向别搞反
- 每走完一条边立刻收缩边界（top++/bottom--/left++/right--），不能拖到循环末尾
