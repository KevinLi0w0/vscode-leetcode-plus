# 54 螺旋矩阵

## 标签
矩阵

## 核心思路
按"上→右→下→左"四个方向逐层遍历矩阵，每遍历完一个方向就收缩对应的边界（top++、right--、bottom--、left++）。当 top > bottom 或 left > right 时停止。时间 O(m×n)。

## 代码模板
```python
class Solution:
    def spiralOrder(self, matrix: List[List[int]]) -> List[int]:
        if not matrix:
            return []

        result = []
        # 定义四个边界
        top, bottom = 0, len(matrix) - 1
        left, right = 0, len(matrix[0]) - 1

        while top <= bottom and left <= right:
            # 1. 从左到右遍历上边界
            for j in range(left, right + 1):
                result.append(matrix[top][j])
            top += 1  # 上边界下移

            # 2. 从上到下遍历右边界
            for i in range(top, bottom + 1):
                result.append(matrix[i][right])
            right -= 1  # 右边界左移

            # 3. 从右到左遍历下边界（需检查 top <= bottom，可能已越界）
            if top <= bottom:
                for j in range(right, left - 1, -1):
                    result.append(matrix[bottom][j])
                bottom -= 1  # 下边界上移

            # 4. 从下到上遍历左边界（需检查 left <= right，可能已越界）
            if left <= right:
                for i in range(bottom, top - 1, -1):
                    result.append(matrix[i][left])
                left += 1  # 左边界右移

        return result
```

### 示例
```
矩阵:
  [1, 2, 3]
  [4, 5, 6]
  [7, 8, 9]

遍历顺序:
  上: 1,2,3 → 右: 6,9 → 下: 8,7 → 左: 4
  进入内层:
  上: 5

结果: [1,2,3,6,9,8,7,4,5]
```

## 关键点
- 四边界 `top/bottom/left/right` 逐步收缩
- 每个方向遍历后立即收缩边界
- 第 3、4 步前需检查边界是否还有效（处理非方阵的剩余单行/单列）

## 易错点
- 下和左两个方向遍历前必须检查 `top <= bottom` 和 `left <= right`
- 否则对于只剩一行或一列的情况会重复遍历
- range 的步长和起止范围要仔细，避免越界
