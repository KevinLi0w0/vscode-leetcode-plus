# 239 滑动窗口最大值

## 📖 故事
一列火车开过，每个窗口里始终站立着最高的那个人。新人进来时比他矮的全被赶走（再也当不了最大值了），最前排的人出窗口了就从队头移走。队列保持从高到矮的排队顺序——队头永远是最高的。

## 🗣️ 人话对照表
| 代码里的 | 人话 |
|----------|------|
| dq | 单调递减队列，存的是下标 |
| dq[0] | 队头——当前窗口最高的人的下标 |
| nums[dq[-1]] | 队尾那个人的高度 |
| i - k | 窗口左边界，超过它就该踢出队头 |
| result | 每个窗口的最大值列表 |

## 📝 带注释课文
```python
from collections import deque

class Solution:
    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        dq = deque()  # 单调递减队列，存下标
        result = []

        for i in range(len(nums)):
            # 队头如果已经滑出窗口左边界，踢掉它
            if dq and dq[0] <= i - k:
                dq.popleft()

            # 新人进来，把队尾所有比它矮的都赶走
            # 因为它们既比新人矮又比新人早离开，永远当不了最大值
            while dq and nums[dq[-1]] < nums[i]:
                dq.pop()

            dq.append(i)  # 新人入队

            # 窗口填满后，队头就是最大值
            if i >= k - 1:
                result.append(nums[dq[0]])

        return result
```

## ⚠️ 易错点
- 队列存的是**下标**不是值，因为要判断是否超出窗口
- 踢队头的条件是 `dq[0] <= i - k`（等于也要踢，因为窗口是 [i-k+1, i]）
- 弹队尾用 `<` 或 `<=` 都行，但用 `<=` 会让队列更短，推荐 `<=`
- `i >= k - 1` 时才开始记录结果，前面窗口还没填满
