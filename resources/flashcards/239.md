# 239 滑动窗口最大值

## 标签
子串

## 核心思路
用一个单调递减的双端队列（deque）存储数组下标，队首始终是当前窗口的最大值。每次右指针扩展时，将队尾所有比当前值小的元素弹出（它们不可能成为最大值），再加入当前下标。队首超出窗口范围时弹出。时间 O(n)。

## 代码模板
```python
from collections import deque

class Solution:
    def maxSlidingWindow(self, nums: List[int], k: int) -> List[int]:
        # 单调递减队列，存储下标，队首是当前窗口最大值的下标
        dq = deque()
        result = []

        for i in range(len(nums)):
            # 移除队首超出窗口范围的元素
            if dq and dq[0] <= i - k:
                dq.popleft()

            # 从队尾弹出所有比当前值小的元素（它们不可能成为最大值）
            while dq and nums[dq[-1]] < nums[i]:
                dq.pop()

            # 当前下标入队
            dq.append(i)

            # 当窗口大小达到 k 时，队首就是最大值
            if i >= k - 1:
                result.append(nums[dq[0]])

        return result
```

## 关键点
- 队列存下标而非值，方便判断是否超出窗口
- 单调递减：队尾弹出所有小于当前值的元素
- 队首是最大值，但需检查是否在窗口内

## 易错点
- 队列存的是下标，不是值
- 弹出队尾的条件是 `< nums[i]` 还是 `<=` 都可以，习惯用 `<=` 可减少队列长度
- `i >= k - 1` 时才开始记录结果，因为窗口需要先填满
